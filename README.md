# HomeNest — Advanced Property Search

This contribution turns the starter files into a responsive real-estate discovery page.

## Included
- Responsive HomeNest landing page and property cards
- Buy / Rent / All listing tabs
- Search by city, locality, or property title
- Property-type and budget filters
- Minimum price, bedrooms, and sorting filters
- Saved properties using browser localStorage
- Property details dialog and enquiry email link
- Property submission preview form
- Mobile navigation and empty-results state

## Run locally
No build tools are required.

1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Try the search filters and save a few homes.

## Important limitations
This is a front-end demo. Property data is stored in `Script.js`; saved homes are stored in the browser. The listing form creates a local preview only. There is no backend, database, authentication, real listing submission, or verified property data yet. The enquiry action opens the user's email client with a prefilled subject.
